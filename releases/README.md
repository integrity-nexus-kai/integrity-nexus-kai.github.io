# TIG Release Layer

This directory is reserved for future canonical TIG publication snapshots.

Planned structure:

- TIG_v1.0.pdf
- TIG2_v1.0.pdf
- TIG3_v1.0.pdf

The release layer is intended to provide:

- stable archival references,
- DOI synchronization,
- reproducible publication states,
- citation-stable scientific snapshots.

Current public TIG releases remain available through the website root during the transition phase.
