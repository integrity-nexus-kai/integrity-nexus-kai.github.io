## Citation and Literature Boundary

The root `CITATION.cff` identifies the website repository. Scientific papers distributed by the site retain their publication-specific bibliographies in their source artifacts or source repositories. The website does not need a synthetic `.bib` unless website prose itself makes externally sourced scholarly claims. Every release link must preserve title, version, source repository, status, license, and a stable checksum or release identifier where available.

## Candidate Control Evidence and Audit Gate

The fourteen Integrity Nexus academic controls apply proportionately to this publication surface. The local evidence path is this profile, Git and release history, root authorship/citation/license files, release metadata, and the source repositories of displayed papers. Before independent audit, verify every public scientific-status statement, link, version, checksum, bibliography handoff, AI disclosure, and license boundary against its authoritative source.
